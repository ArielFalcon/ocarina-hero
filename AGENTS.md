# Project skills

Read [the ocarina catalogue skill](skills/ocarina-catalogue/SKILL.md) before curating song fragments, expanding the catalogue, or preparing aligned audio/melody corpus items. Its detailed pipeline is the quality contract for this project.

Keep downloaded media outside this project. `out` is an ignored symlink to `../ocarina-tabs-media`. Retain only matching original audio clips for new corpus items; distinguish them from synthesized previews.

## Visual identity

Before changing any UI styles, typography, visual assets, component appearance, or interaction states, read [the tapestry design system](docs/design-system.md) and inspect its [interactive reference](docs/design-system/reference.html). Follow its tokens, native-control patterns, embroidery effects, and quality checklist. Extend existing components consistently; preserve their behavior and accessibility. The reference defines the approved visual target, not the current implementation status of the app. Verify UI changes in a browser at mobile and desktop widths; otherwise report `NOT visually verified`.
