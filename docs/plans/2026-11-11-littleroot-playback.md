# Littleroot playback and source fidelity

## Goal

Prevent arrow-key scrolling during instrument control and remove unintended playback artifacts at their shared causes, while preserving source notes and timing by default.

## Confirmed evidence and limits

- Repeated arrow `keydown` events return before `preventDefault` in `src/ui/main.ts`. Controller autorepeat can therefore scroll the page.
- Scheduled oscillators receive a fixed target frequency. Their gain decay ends 215 ms after onset even when the note ends earlier. Each voice also has a 280 ms release that can overlap the next pitch. The event ordering and overlap are confirmed; their contribution to the reported audible pitch changes remains a hypothesis pending native audio rendering.
- With the initial Simplify option enabled, Littleroot loses MIDI 74 and 76 between the section-6 X and R, leaving approximately 820 ms of nominal silence. This is general preparation behavior, not a song-specific exception.
- The supplied capture and saved MIDI share the opening melody but differ in attacks, timing and some notes. Stable analyzed passages do not establish a within-note bend. Do not overwrite the MIDI with this performance or infer physical button gestures from frequency alone.

## Implementation scope

1. **Keyboard:** cancel the default action for recognized controller arrows before the autorepeat return, while applying a held modifier only once. Preserve the existing Ctrl/Meta/Alt shortcut exclusions and release/reset lifecycle. Keep this fix in the keyboard input owner; add a cheap event-level regression for initial and repeated presses.
2. **Playback diagnosis gate:** before editing audio production code, render the three named passages through native Web Audio using the actual engine graph and record the exact prepared notes, gain automation and oscillator targets. Keep full-graph and controlled dry-only diagnostic outputs separate. Test the envelope-ordering and overlapping-release hypotheses individually. A malformed event sequence is evidence of a scheduling defect, but is not by itself proof of the reported pitch sound. Apply only the envelope or release correction whose mechanism is reproduced and isolated; do not mandate removal of overlap beforehand. For a confirmed envelope defect, bound attack/decay to the scheduled duration. For confirmed unintended dry-pitch overlap, bound release using the next onset from the complete schedule, including across pump boundaries. Preserve final release, real rests, fixed oscillator targets, tuning, live controls, resume/cancellation and highlighting. Inspect stop/cancel for the same cause only. If native rendering is unavailable or no mechanism reproduces the symptom, leave the speculative audio change out and report that passage unresolved before extending the plan.
3. **Preparation:** default Simplify to off and project source events directly when simplification is off, preserving their pitches before adaptation, durations and rests. Keep Simplify as an explicit opt-in arrangement operation; retain its existing behavior when selected. Audio's preserveTiming and fixed authored arrangements keep precedence. Set both `scripts/preview.ts` and `scripts/measure.ts` to the same non-simplifying default as the UI; add no new CLI flags. Without a Littleroot-only data patch, check an ascending short passage and repeated notes through preparation. The handwritten renderer in `measure.ts` remains an approximate analysis utility: label its console output and documentation as approximate, without native delay or engine-equivalence guarantees, and do not use it as playback acceptance evidence. Keep any changed envelope rules aligned through a small shared calculation only if needed by both real consumers; otherwise avoid expanding the renderer in this task.
4. **Reference validation:** retain the extracted WAV and provenance. Validate production extraction against independently measured stable capture windows near 1.125–2.025 s, 9.925–10.225 s and 14.725–14.925 s, with documented uncertainty. Run the existing isolated-reference benchmark to prevent source-octave regressions. Do not change detector thresholds or instrument tuning without a new reproducible failure; report any new failure before extending this plan.

## Out of scope

No new pitch-curve IR, bend symbols, detector model, dependencies or source-separation service in the present scope. The capture does not currently justify a within-note bend. If subsequent reference analysis establishes an intentional sustained pitch change, pause that part, present a concrete notation and representation proposal for approval, and do not collapse it into a static bend or silently claim it resolved. Do not alter Lullaby's approved trigger/automatic arrangement, or replace the saved Littleroot notes with a different performance. No commits, publication or deployment.

## Ownership and verification

- Keyboard/input and preparation form one implementation unit; audio scheduling/envelopes form a separate unit with disjoint writable files. The lead owns integration and shared files. Each unit includes focused regression tests and documentation where needed.
- Reproduce failures before production edits, then run focused checks. Include short notes below attack-plus-decay, adjacent distinct pitches across pump boundaries, rests and final release. Native audio diagnostics are a gate before audio edits, not an optional post-fix substitute. If unavailable, report the audio work blocked and do not claim auditory validation.
- Check the controller arrows in the browser at desktop and mobile widths, including a held key, and check that Simplify starts off. Mark any unverified UI as NOT visually verified. Browser checks are included in the requested approval of this plan.
- Obtain an independent read-only integration review, apply one batch of blocker fixes if needed, then run the complete test suite and build once. Leave the development server available for user listening tests.

## Risks and decisions

Bounding dry release can change articulation; validate against the capture without inventing a pitch transition. Echo from the existing room delay is distinct from dry voice overlap and must not be removed based on assumption. The optional Simplify mode remains deliberately lossy and must be identified as such. Restoring all MIDI events can change the displayed TAB and exposes differences between the saved arrangement and the supplied performance. The recommended default preserves the source; automatic simplification remains available only when explicitly selected. Final subjective acceptance requires listening.
